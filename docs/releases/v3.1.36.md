# Tracegate 3.1.36

Refreshes runtime and development dependencies, including transitive packages.
`requirements.lock` is now exported from `uv.lock` and constrains the complete
dependency graph for pip, native host installation, CI, and Docker builds.

- Security updates: aiohttp 3.14.5, Pillow 13.0.0, certifi 2026.10.19,
  multidict 7.1.0, Mako 1.4.3, and cryptography 50.0.2.
- Updates FastAPI, Uvicorn, aiogram, Alembic, PostgreSQL drivers, gRPC/protobuf,
  supporting libraries, and the development toolchain to compatible stable releases.
- Keeps SQLAlchemy on 2.0.55 (`<2.1`) to preserve existing autoflush behavior.
  Pydantic stays on 2.13.5 (`<2.14`), as required by aiogram 3.31.0.
- Supports Python 3.11–3.14. Python 3.15 is excluded because aiogram does not
  support it. The Docker runtime stays on Python 3.12 and PostgreSQL stays on
  major version 16, allowing existing database volumes to remain usable.
- Updates pinned service images to Hysteria 2.13.0, Prometheus 3.15.1, and
  Grafana 13.2.4. Existing rolling Xray, ShadowTLS, and Telemt references remain.
- Adds real PostgreSQL upgrade coverage for unversioned v0.1 databases, stamped
  v0.1 databases, Tracegate 2.1 schemas, and the current schema. Tests verify
  saved connection credentials and exports, repeated startup, and async writes.
- Adds real Pillow QR rendering checks for existing VLESS, Hysteria, and
  Telegram Proxy URLs. CI covers all four supported Python minor versions.
- Preserves percent-encoded database passwords and Unix socket paths when
  passing existing database URLs to Alembic configuration.

This release introduces no database migrations and does not change database
models, enum values, existing connection revisions, secrets, client formats,
ports, or routing topology. Existing migrations keep their historical behavior;
the upgrade checks cover supported VLESS/Reality and Hysteria records, not the
WireGuard rows retired by earlier Tracegate releases.

Deployment requires a separate host activation. Preserve the current private
configuration and runtime overlays, stage a new release, back up the database,
and verify existing client egress before accepting the rollout.
