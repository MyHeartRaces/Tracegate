# Tracegate 4.2.1

Cover-site hardening. No database migration and no change to issued
connections.

- nginx templates (both roles): unknown paths answer 404 and serve
  `/404.html` from the decoy root instead of the home page with 200.
- Endpoint nginx template: the cover-site sign-in is also reachable under
  `/api/account/`, rewritten to the existing `/v1/decoy/` agent handlers.
  `/v1/decoy/` keeps working.
- Agent: the repository frame endpoint answers 404 without a signed-in
  session and is cached privately; the session 401 text no longer names the
  decoy.
- API: the Grafana 401 for a request without a session reads only
  "Grafana session required".

## Upgrade notes

- Only Endpoint runs code that changed. Entry can stay on 4.1.5.
- Hosts with hand-managed nginx configs do not pick up template changes on
  deploy. Apply the same edits there, and deploy decoy content that includes
  `404.html` with every linked page present as a file, before switching to
  `=404`.

Validated by the test suite, lint, host checks and the public release
privacy check.
