# Tracegate 3.1.28

- Restores the dedicated Entry-to-Endpoint Telegram Proxy path as the primary
  route.
- Adds an explicitly configured direct-to-Endpoint MTProto backup without
  sharing the Chain balancer or its carriers.
- Delivers both routes for the same per-user Telemt secret through the bot,
  with the Entry route listed first and the Endpoint route marked as backup.
- Keeps the Endpoint direct route disabled unless
  `MTPROTO_DIRECT_BACKUP_HOST` is set in private runtime configuration.
