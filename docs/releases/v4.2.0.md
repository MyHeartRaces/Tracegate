# Tracegate 4.2.0

Telegram bot overhaul. No database migration and no change to issued
connections or to the API.

- **Russian, newcomer-first bot.** Informal "ты" throughout, a simpler main
  menu, a device page with rename and delete, clear connection choices with a
  recommended default, and one "re-issue" button per connection (revision
  slots live under "advanced").
- **Structured guide.** The private guide file can be YAML or JSON with
  sections and nested pages; plain text keeps working. See docs/bot-guide.md
  and deploy/examples/bot-guide.example.yaml.
- **Robustness.** Buttons from older versions open the current menu, no raw
  API errors reach users, admin actions re-check permissions on every step.

## Upgrade notes

- Only the Endpoint runs the bot; deploy Endpoint. Entry may stay on 4.1.5.
- The welcome version is unchanged, so users are not asked to accept the
  welcome again.
- To use the structured guide, place a YAML file in private runtime storage
  and point `BOT_GUIDE_PATH` at it.

Validated by the test suite (including the PostgreSQL migration tests), lint,
host checks and the public release privacy check.
