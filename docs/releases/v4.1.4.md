# Tracegate 4.1.4

Completes the 4.1.3 command-injection hardening. No database migration and no
change to issued connections.

- The agent runs `nft` for bundle firewall checks and applies without a
  shell, on a fixed agent-owned copy of the firewall config; request-derived
  values never reach a command line.
- Every agent path built from request identifiers is resolved and must stay
  strictly under its root, symlinks included.

## Upgrade notes

- Deploy Entry first, then Endpoint. Upgrading from 4.1.1 also applies the
  4.1.2 and 4.1.3 notes.

Validated by the test suite (including the PostgreSQL migration tests), lint,
host checks and the public release privacy check.
