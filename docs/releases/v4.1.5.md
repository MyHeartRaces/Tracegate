# Tracegate 4.1.5

Fixes the Entry traffic-cap helper so it can run again over an already
applied cap. No database migration and no change to issued connections.

- `tracegate-network-qdisc` keeps an existing matching HTB root instead of
  trying to replace it (HTB cannot be changed in place). Before this fix the
  helper failed on its second run, which made an Entry deploy roll back.

## Upgrade notes

- Deploy Entry first, then Endpoint. Upgrading from 4.1.1 also applies the
  4.1.2-4.1.4 notes. An Endpoint already on 4.1.4 can stay there or move to
  4.1.5; the change only affects Entry.

Validated by the test suite (including the PostgreSQL migration tests), lint,
host checks, the public release privacy check, and a manual double run of the
helper on a live Entry kernel.
