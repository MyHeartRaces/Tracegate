# Tracegate 3.1.33

- Updates the compatibility-checked Hysteria server runtime from 2.10.0 to
  2.12.2 while preserving existing Hysteria 2 client profiles.
- Updates Prometheus from 3.13.2 to 3.14.0 after validating the production
  configuration with the new `promtool`.
- Updates Grafana from 13.1.1 to 13.2.0 after validating its migrations against
  a copy of the production database.
- Keeps Xray, ShadowTLS and Telemt on their intentional rolling `latest` images;
  production validation covers the current stable Xray 26.3.27, ShadowTLS
  0.2.25 and Telemt 3.5.2 builds.
