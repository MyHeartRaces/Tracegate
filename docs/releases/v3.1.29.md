# Tracegate 3.1.29

- Separates actionable Telemt MiddleProxy delivery failures from harmless late
  responses to sessions that have already closed.
- Keeps late Middle-End responses observable with a sustained anomaly threshold
  instead of alerting on every isolated packet.
- Stores agent bundles, base/runtime service configuration, user artifacts,
  tombstones, and the event-state database with owner-only permissions.
- Samples 20 packets per interserver health probe so isolated loss is measured
  with useful resolution instead of appearing as a 33-point step.
- Enables BBR, fair queueing, and TCP MTU probing to reduce the latency impact
  of short packet-loss bursts on Entry and Endpoint.
