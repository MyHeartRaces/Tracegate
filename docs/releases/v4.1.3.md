# Tracegate 4.1.3

Security hardening from the first CodeQL scan. No database migration and no
change to issued connections.

- **Agent payloads are data only.** Bundle-apply requests can no longer carry
  shell commands, and identifiers that become file or directory names must be
  plain names. File writes stay strictly inside their root.
- **Secrets on disk** are created owner-only from the first byte.
- **TLS 1.2 minimum** is explicit for the UDP-over-TCP tunnel and the engine
  probe.
- **Smaller fixes:** generic client config token errors, a stricter
  `<script>` filter in the cover-site sanitizer, read-only CI permissions.

## Upgrade notes

- Deploy Entry first, then Endpoint, as usual. 4.1.2 notes apply when
  upgrading from 4.1.1.

Validated by the test suite (including the PostgreSQL migration tests), lint,
host checks and the public release privacy check.
